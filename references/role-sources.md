# Role Sources and Adaptation Policy

## Roo Code influence

The Role format is inspired by Roo Code custom modes:

- role identity;
- when to use;
- responsibilities and custom instructions;
- capability/permission boundaries.

The delivered roles are newly written for Orca and are not copies of Roo prompts.

## Community role libraries

Large community mode libraries were reviewed for categories and review dimensions. Their content is not imported wholesale because many templates assume:

- fixed framework versions;
- fixed coverage or performance targets;
- specific MCP servers;
- provider-specific tools;
- synthetic business metrics;
- permissions that may be unsafe for the current project.

## Adaptation rules

A Role in this package must be:

- concise;
- tool-neutral;
- subordinate to AGENTS and Task;
- explicit about non-goals;
- explicit about read/write/orchestration permissions;
- linked to reusable professional Skills;
- testable through a completion contract.
