# Product Discovery

## Core principle

Define the problem and outcome before choosing the solution.

## Workflow

1. Identify target users, context, pain, current workaround, and desired outcome.
2. Separate evidence from assumptions and solution ideas.
3. Define in-scope behavior, explicit non-goals, constraints, and irreversible choices.
4. Identify success signals, guardrail metrics, and failure consequences.
5. Compare the smallest viable approaches and what each proves.
6. Escalate only direction choices that belong to the user.

## Required output

- Problem statement
- Users and jobs
- Evidence and assumptions
- MVP scope and non-goals
- Success signals
- Open user decisions

## Rules

- Do not fabricate user research or metrics.
- Do not turn implementation preference into product requirement.
- Avoid roadmap expansion unrelated to the current objective.
- Write acceptance direction in observable terms.

## Completion

The worker must write the requested report, include concrete evidence, state unresolved uncertainty, and return the Task's required completion status. This Skill never authorizes broader scope, branch integration, or orchestration control.
